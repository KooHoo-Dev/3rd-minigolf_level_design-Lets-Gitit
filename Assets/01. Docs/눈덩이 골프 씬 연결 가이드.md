# 눈덩이 골프 씬 연결

기능은 미니골프 씬에서 조합하는 컴포넌트로 구현했습니다. 코스 위치와 아트는 씬에서 직접 배치합니다. 현재 `00. Obstacle Lab` 씬에 공 크기·성장 컴포넌트와 플레이 HUD가 연결되어 있습니다.

## 공통 설정

1. `SnowStageManager`를 꺼지지 않는 `Game` 오브젝트에 붙입니다. 플레이어·`Golf Player Input`·카메라를 연결합니다. 이 컴포넌트가 세 스테이지, 샷 수, 재시작, 화면 표시를 관리합니다. 세 단계 오브젝트는 씬의 공통 `Stage` 오브젝트 아래에 별도 그룹으로 만들고, 각 항목의 `stageRoot`에는 단계별 그룹만 지정합니다. 공통 `Stage`나 매니저가 있는 `Game`은 끄지 않습니다.
2. 공 오브젝트의 `GolfBall`과 함께 `SnowballPlayer`를 붙입니다. 초기·최소 크기 기본값은 1, 눈 위 일반 성장 상한은 3, 전체 최대 크기는 8입니다. `growthPerMeter`로 눈 위에서 굴러 1 m 이동할 때 크기가 커지는 양을 바꿉니다.
3. 공이 굴러도 되는 눈 지형의 충돌체에만 `SnowGrowthSurface`를 붙입니다. 눈이 아닌 바닥에는 붙이지 않습니다.
4. 매니저의 `stages`를 3개 채우고, 각 항목에 시작 위치와 스테이지 오브젝트 묶음을 연결합니다. 1·2단계는 목표 나무, 3단계는 보스와 보급 위치가 있는 오브젝트를 연결합니다. 단계별 장애물·고정 눈더미·열기 공격·낙하 보급 목록도 그 단계 항목에 연결합니다. 매니저는 다음 단계 그룹만 켭니다.

## 오브젝트 설정

- **눈더미:** `Prefabs/Obstacles/Snowball Pickup.prefab`을 배치하고 `SnowPickup.growthAmount`를 조정합니다. 플레이어가 닿으면 한 번 흡수되고, 현재 단계 재시작 시 원래 위치와 상태로 돌아옵니다.
- **성장 장애물:** 충돌체가 있는 오브젝트에 `SnowBreakable`을 추가합니다. `canBreak`, `requiredSize`, `sizeCost`를 설정합니다. 기본 성장 상한보다 높은 크기를 요구하면 눈더미로 추가 성장해야 합니다. 부서질 때 충돌체와 렌더러가 꺼집니다. 영구 벽과 난간에는 이 컴포넌트를 붙이지 않습니다.
- **구출 목표:** 나무 충돌체에 `SnowGoalTree`를 추가하고 동료 Transform과 떨어질 위치를 같은 순서로 연결합니다. 동료 수나 실제 애니메이션 없이도 구출 완료가 동작합니다.
- **나무 보스:** 충돌체가 있는 보스 루트에 `SnowBoss`를 추가합니다. `maximumHealth`, `damagePerSize`와 피격 시 눈더미를 던질 `SnowSupply`를 설정합니다. 보스는 충돌 직전 눈덩이 크기만큼 피해를 받고, 공격 뒤 공의 크기는 초기값으로 돌아갑니다.
- **열기 공격:** 구형 충돌체에 `SnowHeatAttack`을 추가합니다. 공격 위치 후보와 별도의 경고 표시 오브젝트를 지정하고 반경·주기·예고·활성 시간·크기 감소량을 조정합니다. 같은 공격에서 크기 감소는 한 번만 발생합니다. 최소 크기에서 맞으면 해당 단계가 재시작됩니다.
- **눈더미 낙하·투척:** `SnowSupply.snowballPrefab`에 위 눈더미 프리팹을 넣고 낙하 위치와 발사 위치를 연결합니다. 주기 낙하는 `dropPeriodically`를 켜고, `interval`·`warningDuration`·`growthAmount`를 조정합니다. 투척 공급은 보스의 `hitSupply`에 연결합니다.
- **코스 이탈:** 코스 밖을 덮는 Trigger에 `SnowFallTrigger`를 붙이고 매니저를 연결합니다. 직전 샷 위치와 크기로 돌아오며 샷 수에 벌타 1이 추가됩니다.

기존 조준·파워·발사 방식은 유지됩니다. HUD는 스테이지, 샷 수, 눈덩이 크기, 보스 체력, 열기 예고를 표시하며 다음 단계·재시작 버튼을 제공합니다. 스테이지를 다시 시작하면 파괴물, 고정·동적 눈더미, 동료, 보스 체력, 열기와 예약된 낙하가 함께 초기화됩니다.
